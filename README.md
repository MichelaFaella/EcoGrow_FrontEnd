  <b>EcoGrow</b> is an AI-powered smart application for plant identification and care,<br>
  developed for the <i>Smart Applications – Artificial Intelligence</i> exam at the University of Pisa.
</p>

---

This repository contains the **Flutter frontend** of the *EcoGrow* application.  
The app provides a cross-platform (Android & iOS) user interface that allows users to identify plants, receive care recommendations, manage reminders, and interact with an AI-powered backend.

---

## 📱 Features

- 📸 Plant identification via photo capture or gallery upload  
- 🌿 Plant care information (watering, light, environment)  
- 🧠 AI-based plant disease recognition (backend-powered)  
- ⏰ Calendar and reminders for plant care  
- 🔐 User authentication  
- 🎨 Clean, intuitive, and user-friendly interface
